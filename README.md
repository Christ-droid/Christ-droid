## 🚀 Featured Projects

### 🔁 [Automated Remediation Lab — Self-Healing Infrastructure](https://github.com/Christ-droid/automated-remediation-lab)

> **A Proof of Concept of a closed-loop, self-healing infrastructure that detects its own failures and remediates them autonomously — no human intervention required.**

The core idea: infrastructure should be able to fix itself. This lab combines modern monitoring tools with configuration automation to create a full **detect → alert → remediate** cycle.

**How it works:**

| Step | Component | Role |
|---|---|---|
| 🔥 Chaos Injection | Custom Chaos Scheduler (Docker) | Simulates real failures: CPU spike, full disk |
| 📡 Metrics Collection | **Prometheus** + Node Exporter / cAdvisor | Scrapes real-time system metrics |
| 📊 Alerting | **Grafana** (PromQL rules + Webhook) | Detects anomalies, fires alert via HTTP POST |
| 🤖 Auto-Remediation | **Ansible Semaphore** | Receives webhook, runs playbook over SSH to clean or restart |

**Tech Stack:**

![Prometheus](https://img.shields.io/badge/Prometheus-E6522C?style=flat-square&logo=prometheus&logoColor=white)
![Grafana](https://img.shields.io/badge/Grafana-F46800?style=flat-square&logo=grafana&logoColor=white)
![Ansible](https://img.shields.io/badge/Ansible_Semaphore-EE0000?style=flat-square&logo=ansible&logoColor=white)
![Docker](https://img.shields.io/badge/Docker_Compose-2496ED?style=flat-square&logo=docker&logoColor=white)
![Linux](https://img.shields.io/badge/Linux_SSH-FCC624?style=flat-square&logo=linux&logoColor=black)

The entire stack spins up with a single `docker compose up -d`. Grafana and Ansible Semaphore are pre-wired — point, shoot, watch the infrastructure fix itself.

### 🤖 [Network Automation — GNS3 + Python + Ansible](https://github.com/Christ-droid/Network-Automation)

> **Automated deployment and configuration of multi-device network architectures, eliminating manual CLI operations on every device.**

This project tackles one of the most repetitive tasks in network engineering: configuring routers and switches one by one. The answer is automation.

**What it does:**
- Emulates complete network topologies inside **GNS3** (routers, switches, VLANs, OSPF)
- Automates per-device configuration using **Python (Netmiko)** — SSH-based programmatic CLI
- Orchestrates multi-step deployment workflows with **Ansible** playbooks
- Enables consistent, reproducible network provisioning across environments

From there, built a hardening strategy for the equivalent production server based on observed attacker behavior.
